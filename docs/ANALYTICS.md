# 使用统计

自建埋点：页面向 `POST /api/analytics/events` 批量发送事件，Cloudflare D1 保存30天。没有外部分析 SDK、Cookie、设备指纹或广告追踪。匿名会话 UUID 保存在当前标签页的 sessionStorage，不能据此把「会话数」称作独立人数。默认开启；首页数据说明提供关闭开关，并遵守浏览器 Do Not Track。关闭后清空未发送队列。

事件名与属性白名单以 `src/telemetry-schema.ts` 为准。当前覆盖：页面访问、离开与停留；按钮、弹窗与列表切换；分类、范围、收藏、搜索长度与空结果；门店详情与导航；定位申请/成功/失败；地图加载/错误/重试/拖动/缩放/复位；共享评论查看、分享、回复、成功/失败；便宜水筛选、选点、提交、反馈、历史与刷新；接口错误、运行错误、页面加载及LCP表现。未发生或未实施的功能不会伪造事件。

不保存精确位置、搜索词、地址、店名、门店ID、评论正文、用户输入、完整网址、Referrer、堆栈或凭据。服务端再次清洗属性，未知字段或非枚举字符串一律丢弃。按服务端收件时间记时；同事件ID幂等写入。每批最多24条、请求体最多8192字节、队列最多96条；每IP每小时最多120批。失败缓冲有限，网络阻断、关闭统计及页面瞬时关闭可能导致缺数，因此这是行为观察，不能充当计费或精确人数系统。

统计访问受独立 `ANALYTICS_TOKEN` 保护，只留在忽略的 `.env` 与 Worker Secret。`GET /api/analytics/stats?days=7` 使用 Authorization Bearer，只返回聚合会话/访问量、按天计数、按页面/事件计数和白名单维度，未经授权返回403。不把后台凭据放入 Pages。

```sh
npm run analytics:report
# 可指定后端地址和1-30天窗口
npm run analytics:report -- https://poor-map-api.gong7968.workers.dev 7
```

本地事件存入development范围，不混入公开统计；验收事件使用 `qa:<scope>` 隔离并清理，普通用户不能访问。D1免费额度仍受Cloudflare限制，本次没有购买付费分析服务。线上公开统计从新版上线后开始收集，不能恢复此前历史访问。
