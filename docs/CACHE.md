# 门店缓存、采集与步行导航

本轮用途为用户明确的个人研究学习。缓存门店只表示地图厂商收录的参考位置，不证明营业、便宜、有水、库存或活动。所有价格和活动条件继续由独立社区线索提供。

## 读取和更新

- `GET /api/water/candidates?mode=home|water&center=lng,lat&radius=...` 只读共享 D1，永不请求地图厂商。朋友首次打开页面也读这份缓存，不重复下载同一批高德 POI。
- 页面初次定位、切城市、拖动后搜索、改半径、刷新页面，只重新读取自身服务缓存。道路瓦片与 SDK 仍会请求地图服务。
- 「刷新门店」发 `POST /api/water/candidates`，才执行附近实时查询，成功补充或更新缓存。公开刷新每个 IP 每小时最多10次；失败不清空旧数据。高德附近查询每组最多25条，备用每关键词最多20条，截断或部分失败明确显示。
- D1 的 `cached_pois` 和 `cache_runs` 没有 TTL，没有定时刷新或到期删除。查询显示采集日期；名称已标注暂停营业、关闭或装修的点默认排除，其他点营业未知。
- 手动刷新是增量补充，不能凭一次有限查询自动删除未返回的旧门店。门店移动/停业需要用户纠错或后续有证据的管理处理；永久缓存不意味着资料永久有效。
- 浏览器保存最近看过的最多2000个公开门店副本，服务器失败时显示「离线门店副本」。容量上限会淘汰较早看到的副本，但没有时间过期；D1共享库不受该上限影响。冷启动离线没有副本时明确报错，离线时不伪造道路、路线或水价。
- 服务器先按类别、店名/地址文字与地理包围盒筛选，读取最近650个候选，再按精确直线距离筛选，最多展示最近500家并提示上限。导航比较另有限制，见下文。密集首页地图按屏幕网格聚合显示数量，点击展开；选中门店独立显示。聚合不会生成虚构门店、改变列表/缓存记录或转移评论。

`scope` 区分公开与隔离QA；门店保留来源和厂商ID，社区门店只有已确认的 `amapId` 才与高德严格去重。厂商点与社区价格不按模糊名称合并。地图坐标统一 GCJ-02；天地图 WGS-84 双向转换，腾讯/百度明确请求 GCJ-02。

## 城市收集

按用户确认的「北上广深＋新一线＋二线＋大陆省会／首府」去重共56城市。采用[第一财经2025榜单](https://www.yicai.com/news/102638963.html)，因为[2026报告](https://www.yicai.com/news/103204902.html)停止发布城市分级名单。额外加入未在前三层的7个大陆省会/首府。

宁波及四个一线先读取，其余随后扩展。固定关键词：赵一鸣、零食很忙、零食有鸣、好特卖（含HotMaxx）、嗨特购、奥特乐、蜜雪冰城。不是所有超市/餐饮的全国店库。超市候选仍可通过便宜水页的手动周边刷新补充。

```sh
npm run collect:cities -- --cities=priority --budget=1500
npm run collect:cities -- --cities=all --budget=4000
npm run import:cities
# 明确重新采集，保留旧门店、重读分页（会再次消耗地图额度）
npm run collect:cities -- --cities=priority --refresh --budget=1500
```

收集脚本读取本地私密Key，按1.2秒节奏调用官方行政区、文本/多边形搜索；超过单查询200条时拆行政区或地理网格。只接受匹配城市/品牌的门店，排除总部、仓库等。分页日志及去重结果保存在忽略的 `.data/city-collection.json`，中断后可从已读取分页继续，预算或供应商额度错误就停止，不轮换Key绕过限制。导入需私密 `DATA_ADMIN_TOKEN`，不提供前端批量导入按钮。

高德部分分页的 `count` 大于可实际取到的记录，即使继续翻页仍为空。日志分别保留 reported/received/scanned/complete，页面说明「可能不完整」。`complete` 只表示本轮返回分页数量吻合，不证明现实中全部门店或全品牌覆盖；零返回也不能证明没有店。实际城市数量和记录数以 `/api/discovery/summary` 与采集报告为准。

## 步行到折扣店

展开「步行去硬折扣店」，明确选择设备定位、地图中心参考或地图点选的起点，然后规划。设备定位按钮重新定位；权限失败不把默认宁波当成用户位置。手动刷新元数据只关联公开门店ID，不保存查询中心或用户设备坐标。起点与路线只在本次请求/页面内存中使用，不写库、浏览器副本或埋点。

`POST /api/navigation/nearest` 从缓存和社区标记中选取范围内最多8家直线最近的硬折扣店，排除名称标记停业/装修的点；并发2个实际步行算路，单条10秒、整轮25秒。按成功路线的步行长度选最短，并显示比较家数与未比较/失败的提示。路线失败不以直线冒充步行。

高德主用，[腾讯](https://lbs.qq.com/service/webService/webServiceGuide/route/webServiceRoute)、[百度](https://lbsyun.baidu.com/docs/webapi?title=directionlite%2Fguide%2Fwebservice-lwrouteplanapi%2Fwalk)仅在对应服务Key已配置时备选。路线显示道路折线、米数、分钟和文字指引。[高德URI](https://lbs.amap.com/api/uri-api/guide/travel/route)明确携带起终点与 `mode=walk`，跳转至高德网页/App执行后续导航，不在本网页提供后台GPS追踪或语音。

2026-10-09真实云端以高德POI B023E05BX1（宁波天一广场）为参考起点，返回东鼓道好特卖551米/441秒，成功比较3家，折线35点。Chrome桌面及390px手机模拟验收使用该公开点模拟定位，不能证明物理手机GPS、实地入口或App已被调起。SDK初次完成不等于导航缩放后的新瓦片已经绘制，验收等待新瓦片返回再截图。
