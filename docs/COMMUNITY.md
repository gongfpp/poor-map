# 门店与一句话线索

首页默认显示全部，仅启用硬折扣店、蜜雪冰城。量贩零食归入硬折扣；分类配置保留旧分类供后续迭代，当前不展示其他分类或查询其关键词。卡片显示店名、类别、直线距离和真实/示例状态，不显示单品价、购买建议、店铺限价或价格排序。便宜水仍按具体水价比较。

门店详情或右上角「分享线索」可输入一句话，最多500字。选中门店后不需要填价格、链接、截止日期或资格表单。评论及回复保存在独立的 Cloudflare D1 `comments` 表。每条评论可被回复，回复可以再回复，同一讨论以 `rootId` 聚合；后台检查父评论确实属于同店，不能跨店串联。无账号、自动认证或审核机制，所有文字保留「未核验」标识。前端按文本渲染，不执行用户 HTML 或链接。

`GET /api/community/comments?store=<id>` 返回该店最近最多300条评论，`POST /api/community/comments` 接收 `storeId`、`content` 与可选 `parentId`。前端刷新后能从另一浏览器读取；没有实时推送。公开分享每IP每小时最多20次，原IP不保存，仅存短期带盐散列。示例店的留言仍是示例地点的讨论，不会映射成真实门店价格或真实店铺证据。

旧 `poor-map:deals:v1` 本地数据没有删除，也不会自动上传或转成共享评论。旧活动表单已从首页移除；未知的一句话不能被自动认证为霸王餐、免消费或无需抽签。

`npm run verify:community -- <页面URL>` 使用私密 QA 凭据，在 `qa:<scope>` 中验证双浏览器分享、回复、刷新与统计入库，结束后清理该范围。测试不能向公开店铺写验收文字。

2026-10-08：首页默认使用真实共享门店，初始为用户提供的东鼓道好特卖（商圈参考位置）。`GET/POST /api/community/stores`读写D1 stores表；新增需名称、现有两种分类与用户明确的地图点选位置，地址为可选补充。未收到GPS就不会自动给新店填坐标，地图加载失败也禁用选点。新增共享门店属于用户标记、未核验，不被品牌升级成低价证明。未收录地区显示空结果，可看宁波或补充门店。旧示例店的评论保留原ID，不自动转移到真实店铺。
