# 穷鬼地图迭代范围

更新：2026-10-23。用户确认保持极简、干净；本版只做品牌筛选、门店直达分享和定位失败引导。此前建议的内容运营、商品品类扩展、清仓专题、商圈清单及社区反馈扩展均不实施。

## 本版体验与验收

| 核心目标           | 用户可见行为                                                                   | 验收条件                                                                             |
| ------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 更快找到目标品牌   | 首页地图和列表共用品牌筛选，大水地图使用相同品牌识别规则；超盒算NB与盒马NB合并 | 类型切换重置品牌；品牌同时影响标记、列表、数量；未知品牌保留，筛选无结果能恢复       |
| 将同一家店发给朋友 | 门店详情复制直达链接；新浏览器直接打开该店位置与讨论                           | 跨城市、刷新、同页切换链接不串店；剪贴板拒绝时可手动复制；失效链接显示错误与返回入口 |
| 定位失败后仍能继续 | 明示当前查看宁波或保留的地图中心，可选位置、重试、关闭提示                     | 拒绝权限、超时、重试成功均可恢复；手动选择不被迟到的定位覆盖；桌面和手机提示可操作   |

硬约束：保持地图优先，不加宣传区；首页不展示单品价或整店低价排名；投稿仍为门店名称、价格、备注；不新增账号、运营任务、自动采集或付费依赖。本版没有批准技术折中。

品牌筛选作用于当前范围已载的缓存门店，沿用现有最多500家及不完整提示，不宣称现实全量。只列出已载结果中的品牌，已选品牌无结果时保留该选项以便恢复。切换品牌不访问地图厂商；门店链接只包含公开ID，不包含设备位置。详情接口按ID只读社区门店或缓存，不按名字模糊匹配。

列表固定关闭按钮已于2026-10-22完成，不再列为待开发事项。地图数据永久保存、手动刷新、供应商预算和备用接口边界继续以[CACHE.md](CACHE.md)为准，采集现状见[COLLECTION_REPORT.md](COLLECTION_REPORT.md)。后续仅根据明确需求处理数据缺口和可用性问题，不预设第二、第三轮扩张。
