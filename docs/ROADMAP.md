# 穷鬼地图迭代计划

更新：2026-10-15。先增加可信的门店位置，再把用户看到的低价信息连到正确门店。地图数据不等于低价、库存、营业或活动证明。

## 本轮：充实数据与永久缓存

- 在原56城市范围增补乐尔乐、物美、华润万家、盒马鲜生、家家悦。优先宁波及北上广深，按免费接口预算读取其余城市；数量以[采集记录](COLLECTION_REPORT.md)和线上摘要核对结果为准。
- 为宁波天一广场周边单独补充普通超市、独立小店候选，保留品牌未知状态。未知品牌仅进入大水地图的价格待补充候选，不因地图收录就在首页宣称便宜。
- 门店存在D1永久缓存，无TTL、定时更新或到期删除。过时数据仍保留来源和采集日期，由明确手动刷新或社区纠错补充；有限接口未返回旧店时不自动删除。
- 普通访问、切城市、筛选和拖图只读自身缓存；明确点击刷新才请求地图搜索。SDK和道路瓦片按需联网，不作为本地离线地图包。促销的真实截止时间与门店缓存寿命分别处理，活动结束不能冒充仍有效。

## 下一轮：品牌筛选与卡片关闭

在整体交互草图确认后实施，沿用已选的紫色图标胶囊方向。

- 首页和大水地图共用类型、子品牌筛选规则；选中类型后展开品牌，选择“全部品牌”恢复整个类型；筛选同时影响地图、列表、数量和无结果状态。
- 桌面卡片与手机抽屉的关闭按钮固定在顶部；关闭后回到地图，保留筛选和中心；提供重新展开列表入口。
- 单独验收未知品牌小店和品牌无结果情况；手机320/390像素宽度不挤压按钮或遮挡品牌菜单。

## 随后一轮：低成本投稿与社区纠错

- 填写项保持门店名称、价格、备注；位置通过明确选定已知门店、店名加大致区域搜索候选或地图点选完成，不把用户GPS自动当门店坐标。新店没有位置时可保留待定位线索，不放进附近排名。
- 地图搜索优先已有缓存与已实测的高德接口；候选展示来源和地址，由用户确认；没有结果也可手动选点，不虚构搜索结果。其他平台只在真实通过验收后开放。
- 线索、回复可以补充位置。位置纠正保留原记录、修改说明及讨论，不把同品牌附近门店的水价和评论自动转移。
- 每条线索和评论提供互斥、可撤销的赞/踩及回复；限制重复提交和刷票，显示社区争议与更新时间。赞数不能自动变成“已核验”标识。
- 跨浏览器实测共享同步、版本冲突、断网草稿和写入限额；所有写入验收使用隔离QA，不污染公开线索。

## 持续完善：数据质量与备用来源

- 优先修正错误位置、门店入口、停业状态、重复点与缺少规格的水价；保留来源历史，不通过时间自动淘汰门店。
- 收集薄弱区域按人工选择范围继续增补，记录每次请求预算、返回上限及真实新增量，避免反复导入整库消耗写入额度。
- 百度云端调用仍需解决上游响应问题；腾讯接入按此前要求暂缓。备用服务只有配置、真实返回、坐标转换与切换均验收通过后才显示可用。
- 监控供应商请求失败、D1容量与读写额度；付费升级单独确认。监控不触发自动搜店、不采集精确用户位置或评论正文。

每轮发布都核对Pages源码版本，并实测桌面/手机的真实底图、缓存读取与所改交互。持续集成通过或模拟接口成功，不能替代真实服务验收。
