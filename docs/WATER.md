# 便宜水

入口：`#/water`。界面按地图探索组织：全屏地图、紧凑侧栏，手机默认地图加按需展开的底部列表；没有 banner 或宣传区。参考 Nearcade 的地图侧栏和地点详情交互，仅参考布局，不复制代码、素材或其地图 Key。从首页「便宜水」按钮进入，独立页面默认使用设备位置，未授权或失败时回到宁波。手动选择宁波之后，迟到的自动定位结果不会覆盖选择。精确设备位置仅在会话内使用，不写入浏览器收藏 ID 或数据库。

## 真实数据与不确定内容

首批两个记录来自用户在本次任务中提供的线索，不是随机演示数据，也没有宣称商家实时确认：

- 宁波 K11 B1 超市：团购 8.9 元 / 24 瓶 / 550ml，共 13.2L，折合约 0.6742 元/升。平台、品牌、资格、见价日期、库存和有效期未提供，不假定为美团或矿泉水。
- 天一广场东鼓道好特卖：0.9–1.2 元的波动价格。容量、品牌、见价日期和铺位未提供，因此不参与每升排名。

K11 B1 超市的场所资料参考 [中国宁波网 2025-05-28 报道](https://news.cnnb.com.cn/system/2025/05/28/030672327.shtml)，商场范围坐标参考 [商场内地点的高德公开页面](https://www.amap.com/place/B0K36C405Q)。东鼓道的标记为天一广场一侧商圈参考点，未经门店 POI 核验。它们都明确标为商圈位置，不能等同于准确铺位。

每升价格 = 整份水价 ÷（单瓶 ml × 瓶数 ÷ 1000）。波动价格比较采用上限，不将最低历史价当作当前价。大瓶筛选按单瓶 1.2–2.5L，整箱总量不会被误当成大瓶容量。未提供容量的记录留为未知，已卖完、结束和过期的记录默认排除；可勾选历史线索再编辑恢复。额外消费、资格、运费与交通不纳入水价计算，必须看购买说明。

## 数据服务

公开 API：`https://poor-map-api.gong7968.workers.dev`。Cloudflare Workers 与 APAC D1 使用已存在账号的免费方案，没有升级付费计划。免费 CPU 上限由平台控制；不配置需要付费计划的自定义 CPU 限制。额度见 [Workers 免费方案](https://developers.cloudflare.com/workers/platform/pricing/) 与 [D1 免费方案](https://developers.cloudflare.com/d1/platform/pricing/)。本次未在大陆网络现场验收该域名。

本地使用同一接口逻辑和 SQLite，数据库在忽略的 `.data/water.sqlite`。D1 和本地 SQLite 的协议适配位于 `worker/index.mjs` 与 `server/water-db.mjs`。源码不包含生产数据库或后台凭据。

| 接口                           | 用途                                                                         |
| ------------------------------ | ---------------------------------------------------------------------------- |
| `GET /api/water`               | 最近更新的最多 1000 条记录及反馈汇总                                         |
| `POST /api/water`              | 新增未核验社区线索                                                           |
| `PUT /api/water/:id`           | 带版本号修改；冲突返回 409，保留前后记录                                     |
| `POST /api/water/:id/feedback` | 有货、变价、卖完反馈，不认证价格                                             |
| `GET /api/water/:id/history`   | 最近 20 条编辑和反馈                                                         |
| `GET /api/water/config`        | 地图配置状态及公开 JS Key，永不返回服务端秘密                                |
| `GET /api/water/candidates`    | 有高德 Web 服务 Key 后，查询附近零食店、硬折扣和超市候选；每组首批最多 25 家 |
| `GET /api/water/geocode`       | 地址定位；城市或区域级结果保持粗略位置标识                                   |

投稿与编辑无需注册账号，内容会公开显示。每个 IP 每小时最多 20 次公开提交，短期只存带盐散列；查看地图代理、搜店和地址查询有独立限流。提交使用参数绑定与输入检查。没有自动审核或人工审核队列，因此用户信息始终标为未核验。

自动候选超市不能证明有水、低价或库存；候选默认无价格，点标记可填写水价，价格输入不预填为 0。没有门店坐标的新线索会显示在未定位区，不进入附近排名，可通过门店地址查询或手动高德坐标补充。不会以用户 GPS 默认填充公开门店位置。

## 地图密钥与当前缺口

2026-10-07已用Cua Driver在已登录账号创建“穷鬼地图”专用应用、JS Key/安全密钥和独立Web服务Key，仅配置本地 `.env`。真实宁波周边请求返回赵一鸣、东鼓道好特卖等候选，不包含价格。SDK代理观察到初始化使用 `/v3/log/init`，已精确加入允许路径；本地Chrome底图加载遇到SDK网络超时，尚未通过底图验收。

公开Worker没有上传高德Key，也没有购买许可。控制台创建Key页面明确未购买许可的Key仅用于短期、少量测试，并将应用可被公众获取使用列为超授权范围。[官网通用技术许可](https://lbs.amap.com/upgrade)基础版标价5万元/年；个人非研究学习用途需工单确认，并非个人最终报价。只接入底图SDK同样需要JS Key和适用的授权。

公开便宜水继续真实读取、提交、编辑和反馈共享线索，并按位置与单位价格筛选；图中保持已收录地点坐标示意，不伪造道路或自动搜店结果。免费的开源显示库与道路底图来源是两项依赖，其他地图平台的Key、配额与公开使用范围尚未确认。

## 验证

```sh
npm run build
npm test
npm run test:e2e
npm run deploy:api
npm run build:pages
npm run verify:pages
npm run verify:water -- https://gongfpp.github.io/poor-map/#/water
```

共享写入验证使用服务端私密 `QA_TOKEN` 和隔离的 `qa:<scope>` 数据集，两浏览器检查编辑、反馈和冲突，不修改公开价格。每次验证结束清理该隔离数据集。QA Token 不在客户端构建中，不进 Git；普通用户不能访问 QA 数据。

发布前已通过 33 项逻辑/接口检查及桌面与移动浏览器场景；部署后实际线上桌面、手机与双浏览器共享编辑 / 反馈也已通过验证，隔离写入未改公开价格。手机模拟不是物理 iPhone/Safari 或现场买水证明。
